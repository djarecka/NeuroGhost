# Team Experiments

This is the shared sandbox for the NeuroGhost team. Drop your experimental
code, notebooks, scripts, and prototypes here — no review required, no
breakage concerns. Think of it as your personal scratch space inside the repo.

## Structure

Each team member gets their own subdirectory:

```
experiments/
  sulstice/      ← Suliman (Sully)
  puja/          ← Puja Trivedi
  nima/          ← Nima (Niderian Tech)
  dorota/        ← Dorota Jarecka
```

## Guidelines

- **Anything goes** — half-baked scripts, one-off analyses, WIP notebooks.
- Keep your stuff inside your own folder so it doesn't collide with others.
- If something graduates to a real feature, open a PR to move it to the
  main package (`neuro_ghost/`) or `schemas/`.
- Large binary files (models, datasets >10 MB) should go to DANDI/EMBER
  instead — link them here rather than committing them.
